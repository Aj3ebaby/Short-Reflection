# AI Tool Reflection

**Which AI tool(s) did you use?**  
I used ChatGPT as my AI coding assistant throughout the development of my landing page for GlowUp Naturals.

**How did it help you?**  
ChatGPT helped me create a visually appealing and fully responsive HTML landing page from scratch. It suggested a color palette, wrote custom CSS styling, updated color themes to fit my brand’s aesthetic, and provided copywriting support for content like product descriptions and testimonials. It also explained how to structure and organize my HTML and CSS files for best practices.

**What challenges did you encounter?**  
One challenge I faced was choosing the right color combinations to make the text readable while maintaining the brand's earthy vibe. Initially, some text colors blended into the background too much. ChatGPT guided me through adjusting the contrast using hexadecimal color codes and variables.

**What did you learn overall about using AI for coding?**  
I learned that using AI tools like ChatGPT can significantly speed up the web development process. It’s like having a creative partner who can instantly generate ideas, solve code issues, and even help with design decisions. It gave me the confidence to explore HTML and CSS more deeply while keeping things professional and polished.
